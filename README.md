# 元素组合计算器 (Element Combination Calculator)

一个基于 PyQt5 开发的元素周期表组合计算工具，支持双计算系统，提供直观的图形界面和丰富的功能。

## 功能特点

### 核心功能
- 完整的元素周期表显示（1-118号元素）
- 支持中英文/仅中文/仅英文显示模式
- 双独立计算系统，可同时进行不同组合计算
- 支持2项组合和4项组合计算
- 元素选择与保存功能

### 界面特性
- 现代化的图形用户界面
- 支持深色/浅色主题切换
- 可自定义字体和选中颜色
- 可调整的界面布局
- 滚动区域支持大量结果显示

### 数据管理
- 支持保存和加载元素选择
- 自动保存用户设置和偏好
- 完整的日志系统

## 系统要求

- Python 3.x
- PyQt5
- Windows 10 或更高版本

## 安装说明

1. 确保已安装 Python 3.x
2. 安装必要的依赖：
```bash
pip install PyQt5
```

## 使用说明

### 基本操作
1. 启动程序后，左侧显示元素周期表
2. 点击元素进行选择/取消选择
3. 在右侧控制面板使用计算系统

### 计算系统使用
1. 在输入框中输入目标数值（2-118）
2. 选择组合方式（2项或4项）
3. 点击"计算组合"按钮获取结果
4. 使用"清除结果"按钮清空当前结果

### 选择管理
- 保存选择：将当前选择的元素保存为命名配置
- 加载选择：加载之前保存的元素选择
- 删除选择：删除已保存的选择配置
- 清除当前选择：清空当前所有选中的元素

### 显示设置
- 字体设置：自定义界面字体
- 元素显示模式：切换中英文/仅中文/仅英文显示
- 选中颜色：自定义选中元素的颜色
- 关灯模式：切换深色/浅色主题

## 文件结构

- `main.py`: 主程序文件
- `app.ico`: 程序图标
- `element_selections.json`: 保存的选择和设置
- `logs/`: 日志文件目录

## 注意事项

- 程序会自动保存用户设置和选择
- 日志文件保存在 `logs` 目录下
- 建议定期清理不需要的保存选择
